# Reported-only result: LLM extraction performance

Paper table `tab:llm_extraction_performance` is intentionally classified as
`reported_only`. The submitted paper contains the frozen summary values, but this
release does not contain the final 400-paper human gold set together with the
four models' five-run frozen predictions needed to recompute means and standard
deviations. The table is therefore discoverable but is not represented as
independently reproducible.

This exception is limited to the extraction-evaluation table. It does not affect
the released paper-level GPU analysis inputs or downstream paper-result workflows.
