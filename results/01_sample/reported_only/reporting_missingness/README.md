# Reported-only result: reporting-sample missingness models

Paper tables `tab:reporting-incremental-power` and
`tab:reporting-lpm-coefficients` are jointly classified as the second
`reported_only` exception. The paper reports models estimated on 13,745 papers,
but the current release contains organization variables only for 6,895 papers in
the GPU-reporting analysis sample. The full-corpus organizational modeling input
needed to reconstruct both tables is absent.

The two labels count as one exception because they are two presentations of the
same unavailable full-sample model. Their paper values remain documented in the
frozen manuscript snapshot, which is local-only and excluded from Git.
